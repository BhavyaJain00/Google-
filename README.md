# Google Maps Lead Finder

| Folder | What it is |
|---|---|
| [`gmaps-run/`](gmaps-run/) | **The app.** A dashboard for searching Google Maps and viewing every result, plus one-click setup. **Start here: [gmaps-run/README.md](gmaps-run/README.md)** |
| [`google-maps-scraper/`](google-maps-scraper/) | Source code of the open-source scraper the app uses ([gosom/google-maps-scraper](https://github.com/gosom/google-maps-scraper), MIT licence). You don't need it to run the app; it's here for reference and for rebuilding the scraper. |

## Quick start (Windows)

1. Install Python 3 from <https://www.python.org/downloads/> and tick **"Add python.exe to PATH"**.
2. Download this repository (**Code → Download ZIP**, or `git clone https://github.com/BhavyaJain00/Google-.git`).
3. In the `gmaps-run` folder, double-click **`Setup (run once).bat`**.
4. Double-click **`Open Lead Finder.bat`**, then open <http://localhost:8080>.

For Mac/Linux and more details, see [gmaps-run/README.md](gmaps-run/README.md).
